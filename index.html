¿Qué es el hosting?

El hosting (alojamiento web) es el servicio de guardar los archivos de un sitio en una computadora que está encendida y conectada a internet todo el tiempo: el servidor. Cuando alguien escribe la dirección, el servidor le envía esos archivos.

El dominio es el nombre que la gente escribe para llegar a ese servidor. Son dos cosas distintas: se puede tener hosting sin dominio propio (como aquí, usando un subdominio del proveedor) o un dominio propio apuntando a cualquier hosting.

Cómo publiqué esta página

  1. Escribí el sitio. Dos archivos: index.html y estilos.css.
  2. Creé un repositorio público en GitHub llamado actividad-hosting y subí los archivos con git push.
  3. Activé GitHub Pages en Settings → Pages, eligiendo la rama main y la carpeta raíz.
  4. Esperé el despliegue. GitHub construye el sitio en un par de minutos y le asigna el subdominio con HTTPS automático.
  5. Comprobé la dirección final abriéndola desde otro dispositivo.
